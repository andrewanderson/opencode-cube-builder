# Cube Vocabulary Glossary

Cross-cube registry of specialized cube-design terms. This is the source of
truth for what a term means in this project. Never assume the meaning of a
cube-type or format term — check this file first; if a term is absent, ask the
user for the working definition, then add a row here.

| Term | Definition | First recorded | Cubes |
|------|------------|----------------|-------|
| desert cube | Must draft your lands; there is NO basic-land station after the draft. Every land in your deck is drafted. NOT Desert-matters synergies | 2026-08-03 | high-tide |
| blue-prison | Variant desert cube where all basic lands are one color (here: Islands) and other colors rely on that color's duals or colorless fixing. Nearly all decks touch the privileged color | 2026-08-03 | high-tide |
| secret twos | Early-game plays from cards with CMC 1–2 that are only *available* as activated abilities on cards in hand (cycling, evasion, loots, etc.), so a deck with no sub-3 CMC cards still has something to do on turns 1–2. Coined by the Lords of Limited podcast | 2026-08-03 | keruga's day out (idea), oddworld (idea) |
| story-telling cube | Cube where card selection is constrained more by the art / subject-matter of the cards and less by the other aspects of the card | 2026-08-03 | invasion of smolworld (idea) |

## How to add a term

When the user uses or corrects a specialized cube-design term:

1. Confirm the working definition with the user if it's not obvious.
2. Add a row with today's date and the cubes that use it.
3. Update any affected cube's `identity.md` `## Vocabulary` section.
